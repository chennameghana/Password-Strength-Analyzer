# Password Strength Analyzer

This project is a simple cybersecurity-based password analyzer developed using Python.  
It checks whether a password is strong or weak based on different security conditions such as password length, uppercase letters, numbers, and special characters.

The main goal of this project is to understand basic password security concepts and improve awareness about creating secure passwords.

## Features

- Checks password strength
- Detects weak/common passwords
- Calculates password entropy
- Generates SHA-256 encrypted hash
- Provides suggestions to improve password security
- Creates a security report automatically

## Technologies Used

- Python
- Regular Expressions (re)
- Hashlib
- Math Module
